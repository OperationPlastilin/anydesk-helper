# `>_` AnyDesk Helper

**ИИ-техподдержка, которая сама подключается, спрашивает, чинит и учится на своих ошибках.**

[Скачать AnyDeskHelper.exe](https://github.com/OperationPlastilin/anydesk-helper/releases/latest) · один файл · Windows 10/11 · бесплатная модель Qwen

</div>

---

Пользователь пишет: «Поставьте мне Office». Вы создаёте тикет, вставляете его ID AnyDesk и идёте за кофе ☕
Агент подключается, выясняет, что за система, спрашивает у вас лицензию, показывает план и ставит Office
через PowerShell. Всё, что он делает, видно в браузере.

```
🎫 тикет ─▶ 🔌 AnyDesk ─▶ 🔍 проба системы ─▶ 💬 вопросы ─▶ 📋 план ─▶ ⌨️ PowerShell ─▶ ✅ готово ─▶ 🧠 урок в базу
```

## ✨ Что умеет

- **Работает через консоль.** Команды идут в PowerShell пользователя, а вывод возвращается точным текстом
  через буфер обмена AnyDesk, без распознавания картинок. Мышь нужна только для окон вроде UAC.
- **Задаёт вопросы** вам («какая лицензия?») и пользователю: окошко с вопросом прямо у него на экране.
- **Спрашивает разрешения** перед установкой, удалением, правкой реестра и правами администратора.
- **Учится.** После каждого тикета записывает уроки: что сработало, какая ошибка и как её победили.
  В следующий раз подсказывает себе сам. Базу можно править и передавать коллегам.
- **Веб-интерфейс** с тикетами: ход решения вживую, план, команды, скриншоты, пауза и стоп,
  отчёт в Markdown. Тёмная и светлая тема.
- **Обновляется сам** из GitHub Releases при запуске.

## 🚀 Быстрый старт

1. Скачайте и запустите **AnyDeskHelper.exe**. Откроется браузер.
2. **Настройки → Модель**: ключ [OpenRouter](https://openrouter.ai/keys) (модели `qwen…:free`) или
   [DashScope](https://modelstudio.console.alibabacloud.com/) → «Проверить модель».
3. В AnyDesk: **Настройки → Ввод → «Передавать комбинации клавиш»** ✔
4. **+ Новый тикет** → «Запустить агента». Готово 🎉

> 💡 SmartScreen ругается на неподписанный exe: «Подробнее → Выполнить в любом случае».

## 🛡 Честно о безопасности

Интерфейс открыт только на вашем ПК (`127.0.0.1`) и защищён токеном. Пароли и ключи агент не
придумывает, а спрашивает у вас. Вывод команд уходит выбранному провайдеру модели. Подключайтесь
только к тем, кто согласился на помощь.
